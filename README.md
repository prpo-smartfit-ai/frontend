# SmartFit AI - Frontend

React frontend aplikacije SmartFit AI za sledenje vadbi.

## O projektu

SmartFit AI je fitnes aplikacija, ki uporabnikom omogoča sledenje vadbenim aktivnostim in s pomočjo umetne inteligence generira personalizirane vadbene načrte.

## Začetek

### Predpogoji
- Node.js 18+ in npm
- Zagnan user service

### Namestitev

```bash
npm install
```

### Razvoj

```bash
npm run dev
```

Aplikacija bo dostopna na `http://localhost:5173`

### Gradnja

```bash
npm run build
```

### Predogled produkcijske verzije

```bash
npm run preview
```
